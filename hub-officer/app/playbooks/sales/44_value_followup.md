# Block 4 · Continuous engagement: value-based follow-up

After a proposal or a trial invitation, every follow-up must give the buyer a reason to re-engage. **Never** write "just checking whether you had a chance to look at it". That message transfers work to the buyer and signals you have nothing to add.

## What a value follow-up contains (pick one per message)
- **A new insight:**
  - a short reframe;
  - a relevant regulation or insurer-rule change, only if it is in the facts;
  - a common pattern in their segment, stated as a question if it is not backed by data.
- **A tool:** a checklist, the calculator link with their segment pre-filled, a one-page summary the champion can forward internally.
- **An answer to a likely hidden objection** before it is asked: implementation effort, data protection, how cancellation works.
- **A progress nudge in the trial:** "The step that usually shows the first result is importing last month's billing. It takes about 10 minutes."
- **A clean close:** "If this isn't a priority now, no problem. Shall I close the file and come back in 3 months?" This honest breakup often gets the highest reply rate.

## Rules
- Reference the last real interaction ("you mentioned that glosas from insurer X were the biggest issue").
- One idea, one call to action, under 90 words.
- Change the angle each time; never resend the same content.
- Respect the cadence limits and stop immediately on any reply or opt-out.
- **After a "no":** thank them, ask (optionally) for the main reason, and record it. That reason is gold for the weekly review.
